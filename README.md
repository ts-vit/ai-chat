# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## TTS (Text-to-Speech) on Linux

For system TTS (Settings → Audio → Озвучивание), the `tts` crate uses **speech-dispatcher**. Install the development package, for example:

- **Debian/Ubuntu:** `sudo apt install libspeechd-dev`
- **Fedora:** `sudo dnf install speech-dispatcher-devel`
